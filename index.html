비니랩 개인정보처리방침

시행일: 2026-11-03 · 운영자: 비니랩(Beanie Lab)

1. 이 앱이 하는 일

이 앱은 비니랩 채널 운영자 본인이 자신의 YouTube 채널 성과(영상 목록, 조회수, 좋아요, 평균 시청 시간·비율, 트래픽 소스)를 확인하기 위해 쓰는 개인용 분석 도구입니다. 일반 이용자에게 제공되는 서비스가 아니며, 운영자 본인의 Google 계정으로만 로그인합니다.

2. 접근하는 Google 사용자 데이터와 권한(스코프)

  • https://www.googleapis.com/auth/youtube.readonly — 운영자 본인 채널의 영상 목록과 공개 통계를 읽기만 합니다.
  • https://www.googleapis.com/auth/yt-analytics.readonly — 운영자 본인 채널의 분석 지표(조회수, 평균 시청 시간·비율, 구독 증가, 트래픽 소스)를 읽기만 합니다.

영상 게시, 수정, 삭제, 댓글 작성 등 쓰기 권한은 요청하지 않습니다.

3. 데이터의 사용과 보관

  • 가져온 데이터는 운영자의 컴퓨터에서 성과 리포트(로컬 파일)를 만드는 데만 사용합니다.
  • 로그인 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 전송되지 않습니다.
  • 데이터를 제3자에게 판매, 공유, 이전하지 않으며 광고, 프로파일링, 인공지능 모델 학습에 사용하지 않습니다.
  • 다른 사용자의 개인정보는 수집하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

비니랩 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전달할 때는 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 이 앱은 YouTube API 서비스를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

5. 접근 권한 해제와 데이터 삭제

  • Google 계정의 서드 파티 앱 액세스 페이지에서 언제든 이 앱의 권한을 해제할 수 있습니다.
  • 로컬에 저장된 토큰 파일과 리포트 파일을 삭제하면 보관된 데이터가 모두 사라집니다.

Beanie Lab Privacy Policy

Effective: 2026-11-03 · Operator: Beanie Lab

1. What this app does

This app is a personal analytics tool used only by the owner of the Beanie Lab YouTube channel to review that channel's own performance (video list, views, likes, average view duration and percentage, traffic sources). It is not offered to the public, and the owner signs in only with their own Google account.

2. Google user data and scopes accessed

  • https://www.googleapis.com/auth/youtube.readonly — read-only access to the owner's own channel video list and public statistics.
  • https://www.googleapis.com/auth/yt-analytics.readonly — read-only access to the owner's own channel analytics (views, average view duration and percentage, subscribers gained, traffic sources).

The app does not request any write permission: it cannot upload, edit or delete videos, or post comments.

3. Use and storage of data

  • Data retrieved is used only to generate performance reports as local files on the owner's computer.
  • The sign-in token is stored only on the owner's computer and is never sent to any external server.
  • The app does not sell, share or transfer data to third parties, and does not use it for advertising, profiling, or training AI models.
  • The app does not collect personal information about other users.

4. Google API Services User Data Policy

Beanie Lab's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.

5. Revoking access and deleting data

  • You can revoke the app's access at any time at Google Account permissions.
  • Deleting the locally stored token file and report files removes all stored data.
